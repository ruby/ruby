Clears (sets to 0) +count+ bits in +self+; returns +self+.

Examples here use {helper method +string_bits+}[rdoc-ref:String@Helper+Method+string_bits].

With integer argument +offset+ given,
clears +count+ bits beginning at the given +offset+:

  s = "\xFF\xFF"
  string_bits(s)   # => ["11111111", "11111111"]
  s.bit_clear(0)
  string_bits(s)   # => ["11111110", "11111111"]  # Cleared low-order bit in first byte.
  s.bit_clear(15)
  string_bits(s)   # => ["11111110", "01111111"]  # Cleared high-order bit in second byte.
  s.bit_clear(5, 6)
  string_bits(s)   # => ["00011110", "01111000"]  # Cleared high-order bits in first byte,
                                                  # low-order bits in second byte.
  s.bit_clear(100) # Raises IndexError: bit index out of range.

With Range argument +range+ given, clears the bits at the positions covered by the range:

  s = "\xFF\xFF"
  s.bit_clear(0..0)     # Included end.
  string_bits(s)        # => ["11111110", "11111111"]
  s.bit_clear(5..11)    # Included end.
  string_bits(s)        # => ["00011110", "11110000"]
  s = "\xFF\xFF"
  s.bit_clear(0...1)    # Excluded end.
  string_bits(s)        # => ["11111110", "11111111"]
  s.bit_clear(5...12)   # Excluded end.
  string_bits(s)        # => ["00011110", "11110000"]
  s.bit_clear(100..100) # Raises IndexError: bit range out of range.

With {keyword argument +lsb_first+}[rdoc-ref:String@Keyword+Argument+lsb_first]
given as +false+,
the bit numbering within each byte is reversed:

  s = "\xFF\xFF"
  string_bits(s) # => ["11111111", "11111111"]
  s.bit_clear(0, lsb_first: false)
  string_bits(s) # => ["01111111", "11111111"]
  s.bit_clear(15, lsb_first: false)
  string_bits(s) # => ["01111111", "11111110"]
